Downloading and using a font

Install it on Windows

  1. Click "Get it on Google Fonts" on the card you like.
  2. On that page press Get font, then Download all. A zip file arrives.
  3. Right-click the zip and choose Extract All.
  4. Inside, right-click the .ttf file and choose Install.

It now shows up in Canva, Photopea, GIMP, Figma desktop, Paint.NET, and anything else on your PC.

Use it in the game's CSS

  1. Open index.html and find the Google Fonts link near the top.
  2. Add &family=Font+Name to that link, with plus signs for spaces.
  3. In style.css, set font-family to the name in quotes.

Every code on this page is the exact name to paste into font-family.

Making the logo yourself

  1. Photopea (photopea.com) is free Photoshop in the browser. Text tool, then layer styles for gradient, stroke, glow.
  2. Canva is easiest. Upload your font under Brand, or pick from theirs.
  3. Figma if you want vector you can resize forever.

Export as PNG with a transparent background, name it logo.png, drop it in the project folder. The menu picks it up.
